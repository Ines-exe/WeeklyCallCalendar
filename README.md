# Call-endar
This is an application that let's users set weekly call's for them and their loved ones. This app was inspired by me and my highschool friends who have a hard time scheduling calls since we have all become so busy with college. 

## Dependencies
You'll need npm and node

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

## Get a fresh project

run:

```bash
npm run reset-project
```

This command will move the starter code to the **example** directory and create a blank **src/app** directory where you can start developing.
